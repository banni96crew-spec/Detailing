# Приёмка

## Подтверждено локально

- `pnpm lint` — успешно;
- `pnpm typecheck` — успешно;
- `pnpm check:functions` — успешно для четырёх Edge Functions;
- `pnpm test` — 6 тестов успешно;
- `pnpm build` — успешно;
- `pnpm tenant:verify graphite` и `pnpm tenant:verify ember-garage` — успешно;
- `pnpm tenant:publish <slug> --dry-run` — успешно для обеих студий;
- `pnpm test:e2e` — 2 из 2 успешно: клиент выбирает услугу, время, подтверждает запись и видит её в кабинете владельца на мобильном и настольном профилях.

## Реализовано

- независимые студии `graphite` и `ember-garage` с отдельными адресами, метаданными, манифестами, иконками, заставками и областями service worker;
- конвейер `tenant:new`, `tenant:validate`, `tenant:assets`, `tenant:publish`, `tenant:verify`;
- PostgreSQL-миграции с RLS, составными tenant-ключами, историческими снимками цены, исключающим ограничением занятости, транзакционными операциями записи/переноса/отмены, платежами, очередью уведомлений и счётчиками ограничений;
- Edge Functions для публичной записи, кабинета владельца, ограниченного помощника и обработчика Web Push;
- экран записи без регистрации, доступ по хешированному токену, ICS и честное состояние push;
- кабинет владельца с записями, статусами, оплатами, ручной записью и настройками;
- PWA-сборка, безопасные области кэша и исключение приватного кабинета из service worker;
- документация запуска и публикации в `SETUP.md` и быстрый конвейер новой студии в `CLONE-IN-6-MINUTES.md`.
